Estimator runs entirely in your browser: a weighted log-linear scoring rule fit to the empirical group means and Random Forest feature-importance ranking from the underlying study (n = 5,000 posts). It approximates the full scikit-learn pipeline (One-Hot Encoding + Standard Scaling + Random Forest / SVM / Decision Tree / Naive Bayes) described in the project report, which in production would be served from a Flask/FastAPI backend behind this same interface.
